## Outcome

`repoview export --out <dir>` writes a self-contained static copy of the view: the embedded SPA in
static mode plus every API answer as JSON files under `<dir>/data/`. Any static host serves it with
no server. The public documentation includes such an export of repoview's own repository.

## Scope

- `repoview export --out <dir> [--root <dir>]`: write the embedded `web/dist`, set
  `<meta name="repoview-mode" content="static">` in `index.html`, and write `data/snapshot.json`
  and one JSON file per API route the pages read (board, artifacts, per-artifact detail, spec
  roots and IR, quality, vcs, documents), under paths the static-mode client reads.
- The SPA's static mode (`story:web-skeleton` acceptance 6) extended to every page's data.
- The public documentation site for repoview, written with the `docs` skill, embedding or linking
  an export of `beyond10x/repoview` itself, regenerated by `task` and drift-checked.

## Acceptance

- `repoview export --out site/ --root .` on this repository, served by any static file server, shows the same Overview, Plan, Specs and Repository pages as `repoview open`, with no
  request to `/api/`.
- The export contains no run token and no absolute path from the exporting machine's home
  directory.
